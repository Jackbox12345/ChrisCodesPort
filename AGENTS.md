
# Frontend Design Guidelines

## Tech Stack
- React
- TypeScript
- Tailwind CSS

5. https://mobbin.com

## Design Rules

- Create modern, professional interfaces.
- Prioritize responsive layouts.
- Maintain consistent spacing and typography.
- Use subtle animations where appropriate.
- Avoid generic-looking AI-generated layouts.
- Follow existing project conventions.
- Reuse existing components.
- Do not install dependencies unnecessarily.

## Workflow

When implementing a new UI:
1. Inspect existing project components.
2. Review relevant design references when accessible.
3. Propose an appropriate design.
4. Implement using React and Tailwind.
5. Ensure mobile responsiveness.
6. Preserve existing functionality.
